# 🗂️ File Organizer

A simple Python script that automatically organizes files in a folder based on their extensions.

## Features
- Sorts files into categorized folders (Images, Documents, Videos, etc.)
- Skips already organized files
- Works on any directory path

## Version 2.0
- Version 2.0 was added

### Version 2.0 features
- Used `pathlib` instead of `os` 

## Requirements
- Python 3.x
- `os` and `shutil` modules (built-in)
